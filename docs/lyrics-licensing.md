# Lyrics licensing

Only original demonstration lines are bundled. No external lyrics or artwork datasets are included. A production provider must explicitly permit full or timed lyric display for the intended platform and territories.

Record provider agreement, attribution, caching/offline terms, retention deadline, deletion behavior, and distribution rights before implementing the adapter. LyricsDocument.cacheUntil defaults to no permission via nil; the cache stores nothing without an explicit future expiration. The current cache is memory-only.
