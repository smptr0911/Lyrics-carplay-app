# 확정한 제품 방향

사용자 결정, 2026-11-12:

- 우선순위는 Spotify 곡 정보·재생 제어와 주차 영상.
- 동기화 가사는 권리와 플랫폼 허용이 확인된 소스에서만 제공.
- Spotify 가사·영상 동기화는 허용 근거가 확보되기 전까지 제외.
- 가사 공급자 계약은 아직 없으며 교체 가능한 API와 로컬 개발 서버부터 구성.
- Mac/Xcode와 실제 iPhone은 사용 가능. Spotify 개발자 앱은 생성 절차부터 필요.

## 기능별 플랫폼 판단

| 기능 | 현재 경로 | 배포 전 남은 조건 |
| --- | --- | --- |
| Spotify 메타데이터·제어 | iPhone의 공식 App Remote | Client ID, 계정 제한·SDK/기기 검증, 정책 검토 |
| 음악 앱 선택 | iPhone 설정 | 소스별 동작·권한·전환 검증 |
| 데모 동기화 가사 | iPhone, 원본 가사 | 접근성·기기 검증 |
| 실제 곡 가사 | 허용된 소스 + 별도 가사 API | 공급자 계약·매칭·인증·출처·보관 정책 |
| 주차 영상 | iPhone AVKit + 지원 차량 AirPlay | 영상 권리·차량 지원·시스템 제한 검증 |
| CarPlay 목록 | 시뮬레이터 전용 시스템 템플릿 | Mac 실행 확인, 생산용 적격성·권한·설계 승인 |
| 차량 화면의 직접 영상 탐색 | 미구현 | 적합한 SDK·영상 카테고리 권한·지원 차량 |
| 차량 화면 스크롤 가사 | 보류 | 현재 검토에서 승인된 경로가 확보되지 않음 |

일반 iPhone/Archive는 CarPlay 장면·권한을 활성화하지 않습니다. Apple 승인·가사 계약·실기기 검증이 없는 기능은 출시 설명에 포함하지 않습니다. [CarPlay 검토](carplay-feasibility.md)와 [Spotify 정책](spotify-integration.md)을 함께 관리합니다.
